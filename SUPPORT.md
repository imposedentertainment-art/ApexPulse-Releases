# Support

For ApexPulse installation, update, or gameplay problems:

1. Check the release notes for your installed version.
2. Confirm that the APK came from this official repository.
3. Include your ApexPulse version, Android version, device model, and concise reproduction steps when reporting a problem.
4. Remove personal information, account credentials, tokens, and other secrets from logs or screenshots before sharing them.

Use the repository's **Issues** tab for general support if issues are enabled. Do not use public issues to report security vulnerabilities; follow [SECURITY.md](SECURITY.md) instead.

ApexPulse's simulator and session features are intended to run locally on the Android device. Internet access is used for the optional update check and APK download.
